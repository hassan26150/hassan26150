## 👨‍💻 About Me

I'm an **AI-focused software engineer** who builds complete products, from the ML model and inference API to the mobile or web client. My work combines **LLM integration, trained ML models, and production-style backend architecture**, so AI features ship as working systems and not as notebooks.

- 🤖 Built **LLM-powered assistants** (LLaMA 3.3 70B via Groq) with structured JSON outputs and Redis-backed conversational memory
- 🧠 Trained and deployed **Scikit-learn models** behind a decoupled **FastAPI inference service**
- 🎨 Built **generative AI pipelines** (FLUX.1, Stable Diffusion XL) with retry/backoff and rate limiting
- 🏗️ Designed **microservice architectures** with Node.js/Express and Python/FastAPI
- 🔐 Security-first engineering: JWT, bcrypt, rate limiting, OWASP-aligned validation
